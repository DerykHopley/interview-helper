## Situation

We set out to build personalised dashboards for our analytics product: layouts that rearranged themselves around each user's habits, with automatically suggested reports. It was meant to underpin the product's future, but it took about six months with interruptions, and the business changed direction several times meanwhile.

## Task

Deliver the feature and integrate it into the existing platform.

## Action

I led the team through building the underlying engine and fitting it into the platform. We kept going as priorities shifted because the feature had been agreed as strategic, and we didn't stop to check whether that was still true.

## Result

We shipped it, but by then customers had lost interest in the approach, so it added little value. Since then I set review points on long projects to ask whether the original reason still holds.
